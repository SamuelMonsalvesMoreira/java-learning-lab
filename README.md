## ▶️ Como executar um exercício

1. Faça o clone deste repositório:

```bash
git clone https://github.com/SamuelMonsalvesMoreira/exercicios-java-basico
```

2. Abra a pasta do projeto no IntelliJ IDEA.

3. Aguarde o IntelliJ configurar o JDK e baixar as dependências, caso o exercício utilize Maven.

4. Abra a classe que contém o método:

```java
public static void main(String[] args)
```

5. Clique no botão verde ao lado do método `main` e selecione **Run**.
