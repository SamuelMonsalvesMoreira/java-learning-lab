## Organização das soluções

```text
solucoes/
├── exercicio-01-tabuada/src/Tabuada.java
├── exercicio-02-imc/src/Imc.java
├── exercicio-03-pares-impares/src/ParesImpares.java
└── exercicio-04-divisao/src/Divisao.java
```

Cada exercício mantém sua própria pasta `src`. O nome da pasta identifica o exercício, por isso a classe pode ter um nome simples, como `Tabuada`, `Imc`, `ParesImpares` ou `Divisao`. As pastas podem ter hífens, mas o nome do arquivo Java deve ser exatamente igual ao nome da classe pública e não pode ter espaços ou hífens. Quando terminar e testar uma solução, marque o item correspondente no checklist.
