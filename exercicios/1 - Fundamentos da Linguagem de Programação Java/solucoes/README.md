# Soluções — Fundamentos da Linguagem Java

Nesta pasta estão minhas soluções para os quatro primeiros exercícios de fundamentos da linguagem Java.

## Exercícios resolvidos

1. Cálculo da idade a partir do ano de nascimento;
2. Cálculo da área de um quadrado;
3. Cálculo da área de um retângulo;
4. Cálculo da diferença de idade entre duas pessoas.

## Como executar no IntelliJ IDEA

1. Abra a pasta deste repositório no IntelliJ IDEA;
2. Acesse a pasta `src`;
3. Abra a classe do exercício desejado;
4. Clique no botão verde ao lado do método `main`;
5. Selecione **Run**.

Cada exercício possui seu próprio método `main` e pode ser executado separadamente.
